# AI Design Reasoning Examples

This directory teaches the model how to think before generating SVG.

The goal is not to memorize visual effects. The goal is to reproduce design decisions.

Each case follows:

1. Understand user intent
2. Define visual objective
3. Select V2 system
4. Build composition
5. Apply tokens
6. Choose material behavior
7. Validate against anti-AI rules

## Case Structure

```
User Request
    ↓
Design Analysis
    ↓
Archetype × Palette × Layout
    ↓
Composition Decision
    ↓
Material Decision
    ↓
Typography Decision
    ↓
Motion Decision
    ↓
Quality Review
```

Good SVG generation starts with art direction, not decoration.
