# SVG 可视化编辑器（editor.html）设计规格

- 日期：2026-08-25
- 状态：已获用户批准的设计，待实现
- 交付仓库：svg-optimization-skill
- 决策过程：视觉伴侣会话 `.superpowers/brainstorm/visual-20260824/`（界面稿、主题小样、功能清单均在其中）

## 背景与目标

技能当前只有 `scripts/measure_text.html`（量文字宽）和静态画廊 `preview.html`。
用户三大痛点：

1. 没有 BioRender 式的可视化编辑：拖动元素无参考线、无「噔的一下」吸附对齐；
2. 配色单一不好看；
3. 组件太「AI 风」、大小不适配（文字撑不撑容器全靠手算）。

本规格定义一个**自研单文件 HTML 可视化编辑器** `scripts/editor.html`，
以「拖拽 + 全套智能吸附」为核心体验，同时内置主题系统与自适应组件库，
覆盖以上三个痛点。用户已确认的决策：

| 决策点 | 结论 |
|---|---|
| 优先级 | 编辑器核心先行；配色/组件在编辑器内一并解决 |
| 吸附档位 | 全套 = 参考线吸附 ＋ 等距检测 ＋ 同类识别语义吸附 |
| 编辑能力 | 全套：移动/改字自动适配/缩放/换色套主题/组件库插入 |
| 导入导出 | 拖入文件打开；File System Access API 直接写回原文件 |
| 质感维度 | **砍掉**。所有主题统一自带柔光晕+细阴影的精致处理，不做独立质感风格 |
| 技术路线 | 自研单文件 HTML，零依赖、离线双击即用 |

## 范围

**做**：`scripts/editor.html` 单文件编辑器；12 套主题 × 4 布局 × 4 混色手法内置；
SKILL.md / README.md / design-patterns.md 同步更新（编辑器进入工作流的位置）；
node 单测扩展。

**不做**（本期明确排除）：独立质感皮肤（毛玻璃/黏土/线稿）；多人协作；
除 SVG 外的其他格式导入；移动端触控优化。

## 1 · 总体架构

单文件内八个模块，职责单一：

| 模块 | 职责 | 对外接口 |
|---|---|---|
| Loader | 拖拽/按钮读入 SVG 文本 → DOMParser 解析 → 图元树 | `load(text) → Document` |
| Model | 图元树 + 选择集 + 命令历史栈 | `execute(cmd)` / `undo()` / `redo()` |
| Renderer | 将图元树渲染进画布 `<svg>` 内容层 | `render()` |
| Overlay | 选择框、8 手柄、参考线、间距徽章、同类气泡、越界高亮；独立 SVG 层 | `show(state)`；**永不进入导出** |
| SnapEngine | 全部吸附计算（纯函数） | `compute(movingBox, scene, opts) → SnapResult` |
| TextMeasurer | canvas measureText，与 measure_text.html 完全相同 font stack | `measure(text, fs, weight) → width` |
| ThemeEngine | 主题 token → SVG 属性映射；三档应用范围 | `apply(theme, scope)` |
| Persistence / Exporter | 写回原文件、草稿、PNG、复制源码；导出净化 | 见 §5 |

验收：
- [ ] 双击 editor.html 离线可用，无任何外部请求（断网测试通过）
- [ ] 文件 ≤ ~150 KB；≤500 个元素的 SVG 拖拽帧率无明显卡顿

## 2 · 吸附引擎（核心体验）

规则（默认全开，可在「吸附控制台」分别开关）：

1. **参考线吸附**：拖动中，被拖元素的四边/中心 与 场景内其他元素的四边/中心、画布四边/中心 对齐时显示红色参考线；距离 ≤ 触发值时松手自动吸住。触发距离默认 6px，可调 2–16px。
2. **等距检测**：拖动中计算与最近邻的左右/上下间距；左右（或上下）间距相等时两枚红色间距徽章同时点亮。只提示不强制。
3. **同类识别**：聚类规则 = 相同子元素签名（如 g 内 rect+text）且包围盒宽高相差 ≤15%。命中后吸附到：同列 x / 同行 y / 同类宽高 / 与相邻同类等间距。气泡与状态栏说明理由（例：「第 3 个徽章 · 宽 96 = 同类」）。
4. **临时豁免**：按住 Ctrl 拖拽 = 关闭全部吸附自由放置。
5. **参考线降噪**：同屏最多显示 4 条参考线，优先中心 > 边 > 等距。
6. **越界警告**：任一元素包围盒超出画布即边缘红色高亮（防溢出是 skill 既有铁律）。

验收（SnapEngine 以纯函数单测覆盖）：
- [ ] 给定场景与移动框，各规则返回正确的吸附目标与修正量（用例含：双边同时命中、等距命中、同类列对齐、Ctrl 豁免）
- [ ] 拖动全程 ≤16ms/帧的计算耗时（500 元素场景）

## 3 · 编辑能力

- 移动：拖拽；方向键 1px，Shift+方向键 10px；Alt+拖拽 = 复制一份
- 缩放：8 向手柄，Shift 等比；数值输入框 X/Y/W/H 精确控制
- 文字：双击进入行内编辑 → 实时 TextMeasurer → `rect.width = 文字宽 + 2×padding` 自动撑开，text-anchor 保持不变（直接解决痛点③）
- 多选：拖框框选、Shift 加选；多选后出现对齐分布工具栏（左中右/顶中底/水平垂直等距分布）
- 图层：列表拖动排序、眼睛隐藏、锁头锁定、双击重命名
- 右键菜单：复制/粘贴/删除/置于顶层/置于底层/存为我的组件
- 自定义组件收藏：存 localStorage；再次插入时按当前主题 token 重新着色
- 工具切换：V 选择 / T 文字 / H 抓手；完整快捷键表写入 README

验收：
- [ ] 双击改字后容器自动适配，左右内边距保持相等（回归用例固定）
- [ ] Alt 复制、方向键微调、多选分布各有单测或脚本化验证

## 4 · 主题系统（配色 × 布局 × 混色）

- **12 套主题**（T1–T12，见 visual-20260824 小样）：极光蓝紫(亮,默认)、生物青绿、深空霓虹、经典蓝橙、樱花粉、落日橙粉、葡萄紫、柠檬苏打、森林墨绿、石墨鎏金、海洋蓝青、极简黑白
- Token 集：`bg / surface / primary(3 阶) / accent / title / body / success / warning / danger / neutral(4 阶)`
- **4 种布局模板**：左文右标（默认）/ 居中对称 / 标题+特性格 / 斜切动势
- **4 种混色手法**：纯色底（默认）/ 极光渐变网 / 渐变色带拼接 / 中性底×多彩功能位
- 应用范围三档：全局换肤（默认）/ 仅选中元素 / hover 实时预览点击确认
- 所有主题统一自带精致处理（柔光晕、细阴影、统一圆角半径），无独立质感风格
- 字号阶梯随布局模板走（banner: 72/26/18；mockup: ≥14）

验收：
- [ ] 12×token 键全集完整性有 node 断言
- [ ] 切主题后所有取色元素更新，未取色元素（用户手动改过的颜色）不被覆盖并提示

## 5 · 导入导出与持久化

- 打开：拖文件进窗口 / 按钮；支持含 defs/gradient/filter 的手写 SVG
- **保存 = 写回原文件**：File System Access API（Chrome/Edge），授权一次后续静默写回；不支持的环境降级为下载并顶部提示
- PNG 导出：2x/4x；一键复制干净 SVG 源码
- 导出净化：剥离 overlay 与一切编辑器痕迹；坐标取整到 0.1；xmlns 保证；导出体积不超过原文件的合理倍数
- 自动保存草稿：每步操作静默写 localStorage（key=文件名）；重开同一文件时提供「恢复草稿」

验收：
- [ ] parse → export 幂等性测试（对已符合净化规范的文件，不改任何内容时导出与原文仅空白/引号风格差异；首次编辑保存时允许一次性坐标取整）
- [ ] 断开授权（拒绝权限）时降级下载成功且提示可见
- [ ] 关闭标签页后重开可恢复草稿

## 6 · 错误处理

| 场景 | 行为 |
|---|---|
| 非 SVG / 解析失败 | 明确报错弹层，指明原因行号（若可得） |
| 外链图片/href | 提示将忽略或要求内嵌，不静默失败 |
| 写回权限被拒 | 自动降级下载 + 提示 |
| 超大文件（>1MB） | 建议拆分的警告，仍可继续 |
