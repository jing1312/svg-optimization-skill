# Successful Composition Memory

Store composition patterns that consistently produce strong SVG results.

## Hero Pattern

Structure:

```
One visual focus
+
large negative space
+
clear typography hierarchy
+
controlled atmosphere
```

Suitable for:

- launches
- brand statements
- premium products

## Object Showcase Pattern

Structure:

```
Material object
+
soft environment
+
secondary information
```

Suitable for:

- products
- crafts
- physical materials

## Editorial Pattern

Structure:

```
Strong headline
+
intentional grid
+
minimal supporting elements
```

Suitable for:

- posters
- reports
- cultural content
