# Anti-AI Visual Rules

These rules prevent generic generated SVG aesthetics.

## 1. Remove Decoration Without Meaning

Every major element must answer:

- What message does it communicate?
- What visual noun does it represent?
- Why does it belong here?

If it cannot answer, remove it.

## 2. Forbidden Patterns

### Random glow objects

Avoid:
- floating gradient circles without purpose
- repeated light blobs
- decorative stars everywhere

Light must have a source and direction.

### Generic glassmorphism

Avoid stacking:
- blur
- opacity
- white border
- rounded rectangle

Glass is a material, not a preset.

### Sticker composition

Avoid:
- unrelated cards floating together
- icon + title + subtitle repeated grids
- centered collections without hierarchy

## 3. Composition Rules

Prefer:
- one primary motif
- one supporting gesture
- one controlled detail

Luxury comes from subtraction.

## 4. AI Output Review

Before finalizing, check:

- Is the first impression recognizable without text?
- Is there one clear visual hierarchy?
- Could removing one element improve it?
- Does the style feel authored rather than assembled?
