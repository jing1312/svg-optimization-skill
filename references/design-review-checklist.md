# V2 Design Review Checklist

Use after SVG structural validation.

## Before approval

### Intent

- [ ] The asset has one clear message.
- [ ] Every major element has a reason to exist.
- [ ] Decorative elements can be removed without harming meaning.

### Composition

- [ ] Primary focus is obvious.
- [ ] Layout follows a grid or intentional asymmetry.
- [ ] Negative space is preserved.

### Color

- [ ] Colors have assigned roles.
- [ ] Accent colors are limited.
- [ ] Light direction is consistent.

### Typography

- [ ] Text hierarchy is clear.
- [ ] Font sizes follow the token scale.
- [ ] Line spacing supports readability.

### Material

- [ ] Effects represent physical behavior.
- [ ] Blur and glow are controlled.
- [ ] Shadows support depth.

### AI Smell Test

Ask:

"Would this design still feel intentional if all decorative effects were removed?"

If no, simplify before release.
