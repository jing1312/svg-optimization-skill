# Motion Library

Motion is part of the visual system. It should reveal hierarchy or material.

## 1. Ambient Motion

Purpose: atmosphere.

Examples:
- slow light drift
- subtle gradient movement
- environmental breathing

Rules:
- duration: 8–20 seconds
- low amplitude
- never distract from content

## 2. Material Motion

Purpose: show physical properties.

Examples:
- glass reflection sweep
- paper shadow response
- metallic highlight movement

Rules:
- duration: 2–6 seconds
- tied to a material explanation

## 3. Interaction Motion

Purpose: user feedback.

Examples:
- hover response
- focus transition
- state change

Rules:
- duration: 300–700ms
- use consistent easing

## Motion Anti-patterns

Avoid:
- constant movement everywhere
- random floating objects
- excessive bouncing
- animation added only because SVG supports it

A still frame should already feel complete.
